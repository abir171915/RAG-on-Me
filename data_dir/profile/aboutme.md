I am Md Abir Hossain an MSc graduate in Artificial Intelligence and Machine Learning from the University of Birmingham with hands-on experience building end-to-end AI systems across generative AI, computer vision, time series forecasting and deep learning. 

My MSc dissertation was focused on optimising fNIRS source-detector placement for auditory cortex activation using finite element modelling and Jacobian sensitivity analysis in MATLAB. Working on a real neuroimaging problem taught me not only how to build models but how to think carefully about the physical system behind the data and what it actually means to extract reliable signal from noisy measurements. 

Before my MSc, I worked as a Data Science Intern at Aziz & Brothers in Bangladesh. For my BSc thesis, I built SlotFinder, a spatio-temporal parking prediction system trained on real-world data from 408 buildings across 7 locations in Dhaka. I used K-Means clustering to group locations and trained a Stacked LSTM model per cluster, which outperformed the previous existing works. The work was co-authored and published at IEEE ICCIT 2022, which was my first real experience with the full research cycle from data collection through to publication.

Alongside my academic work, I have independently built several Machine Learning and AI projects including a pneumonia detection classifier using PyTorch and ResNet18, a multi-stage RAG pipeline using LangChain and Pinecone. I am currently working on DataChat, an agentic data analyst application using LangGraph and the Claude API with LLM observability via Langfuse.
